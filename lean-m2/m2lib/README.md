# m2lib — exact mathematics in ISO Modula-2

This library implements the computable definitions used by
google-deepmind/formal-conjectures (Lean 4 and Mathlib) as GNU Modula-2 modules. Every result is exact. Capacity limits are explicit: a procedure returns `FALSE` when the true value would not fit, and never returns a wrong or approximate value. See MODULES.md for the module inventory and its limits.

## Build and test

```sh
GM2=/path/to/gm2 GM2LIB=/path/to/gcc/lib64 ./build.sh
```

`build.sh` does the following:

1. Compiles every module in `src/` with `gm2 -fiso -c`.
2. Links each test program in `tests/` against the objects.
3. Runs every test program.
4. Builds `tests/expect_fail/FailCheck`, which must fail.

Each command is printed together with its exit status. The script exits non-zero if any step fails. `GM2LIB` is optional; if set, its value is recorded as the runtime library path of the test binaries.

gm2 is part of GCC 13 or later; build it with `--enable-languages=c,m2`.

## Use

```modula2
IMPORT Combinatorics, BigNat;
VAR b: BigNat.T; s: ARRAY [0..2600] OF CHAR;
...
IF Combinatorics.ChooseBig(1000, 500, b) AND BigNat.ToDecimal(b, s) THEN ... END
```

To compile and link your own program:

```sh
gm2 -fiso -Isrc -c src/<Module>.mod -o build/<Module>.o   # once per module used
gm2 -fiso -Isrc prog.mod build/*.o -o prog
```

## Tests

| Program | Checks | Source of the expected values |
|---|---|---|
| TestOeis | 559 | The `theorem a_K : a K = V` statements in FormalConjectures/OEIS/*.lean, which Lean itself checks. Generated by `tests/gen_oeis_tests.py`. |
| TestCore | about 1670 | Naive Python transcriptions of the Mathlib definitions (`tests/gen_core_tests.py`). |
| TestBig | about 980 | Python exact `int` and `Fraction` arithmetic (`tests/gen_big_tests.py`). |
| TestSearch | about 170 | Brute-force Python predicates (`tests/gen_search_tests.py`). |
| TestSeq | 86 | Values written out by hand from the Lean definitions. |

Boundary cases are included throughout: 0, 1, 2^64 − 1, empty lists, division by zero, base 0 and base 1 digits, singular matrices, and values just past each capacity, which must return `FALSE`.

To regenerate the generated tests, run in `tests/`:

```sh
python3 gen_core_tests.py > TestCore.mod
python3 gen_big_tests.py > TestBig.mod
python3 gen_search_tests.py > TestSearch.mod
python3 gen_oeis_tests.py <formal-conjectures>/FormalConjectures/OEIS ../src > TestOeis.mod
```
